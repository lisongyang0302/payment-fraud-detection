# 项目三：支付反欺诈识别（不平衡学习 + 成本敏感阈值策略）

基于 Kaggle 经典数据集 [Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)（欧洲持卡人真实交易，284,807 笔，特征经 PCA 脱敏，金额单位欧元），
完整走一遍 **数据体检 → 不平衡学习 → 策略阈值优化** 的反欺诈项目流程。

## 核心结果

数据：284,807 笔真实交易（去重后 283,726，其中欺诈 **473 笔**，不平衡比 **1:600**）。金额单位：欧元。

| 指标 | LR (class_weight) | LightGBM |
|---|---|---|
| **AUC** | 0.9663 | **0.9772** |
| **AUPRC** | 0.6877 | **0.8200**（不平衡场景比 AUC 更有意义的指标） |
| 阈值 0.7 时（测试集 85,118 笔） | 挽回率 88.7%，误拦 1,061 笔（1.247%） | 挽回率 76.1%，误拦仅 4 笔（0.005%） |

> 模型对比结论：LightGBM 在 AUPRC 上显著优于 LR（+0.13），且误拦几乎为零（客户打扰极小）；
> LR 挽回率更高但误拦更多——最终选型取决于业务成本结构（漏放损失 vs 误拦成本与客户体验）。
> 实现代码见 `src/step2b_model_compare.py`，阈值扫描见 `src/step3_cost_threshold.py`。

## 时间外推（OOT）验证

**随机切分会显著高估泛化性能**。按 Time 列切分（前 70% 训练 / 后 30% 全未来交易）重跑：

| 切分方式 | LR AUPRC | LightGBM AUPRC |
|---|---|---|
| 随机切分 | 0.688 | 0.820 |
| **时间外推** | **0.767** | **0.080** |

- LightGBM 在时间外推下大幅衰减（树模型对近期分布过拟合），评估必须以时间外推为准；
- 线性模型在时间外推下反而更稳；
- 口径披露：Time 全程仅约 2 天（训练窗口 36.9 小时 / 测试窗口 11.1 小时），测试期欺诈基率 0.126% 低于训练期 0.184%——本验证仅证明「随机切分高估」，不外推长期漂移结论；
- 脚本：`src/step2c_oot_validation.py`。

## 成本矩阵（阈值选择的业务口径）

**假设**：漏放 1 笔 = 损失该笔全额（欧元，激进假设——现实中核销有回收与责任分担）；误拦 1 笔 = 人工审核 5 欧。

99 档扫描（`src/step3b_cost_matrix.py`，模型为 **LightGBM**，随机切分口径）：成本最优阈值 **0.74**（最优平台期 0.74–0.90），总成本 31 欧 = 漏放 10.65 + 误拦 4×5（vs 默认 0.5 的 55 欧，**降 44%**）。
口径披露：测试集 85,118 笔，阈值 0.74 下 TP=107 / FP=4 / FN=35，漏放 35 笔均为小额（合计 10.65 欧），大额欺诈已全部拦截——漏放损失结构由模型排序质量决定。

**部署口径（OOT 复扫，`src/step3c_lr_oot_cost.py`）**：随机切分选点不可直接部署（LightGBM 时间外推崩盘，见上节）。在时间外推测试集（85,118 笔，欺诈 107 笔）上对 LR 复扫 99 档：总成本随阈值单调下降至扫描边界 0.99——总成本 465 欧 = 漏放 30.32 + 误拦 87×5，较默认 0.5 的 11,995 欧降 96%。结论：**部署阈值必须按时间外推口径定期复扫**，随机切分下的最优点只作方法学演示。

## 业务洞察

1. **欺诈形态**：欺诈笔中位金额仅 9.8 欧元——小额试刷（验证卡可用性）后再大额盗刷是典型手法；
   数据侧单看金额无法识别，需要行为特征（时间密度、金额突变）。
2. **不平衡的正确打开方式**：不用准确率（全预测正常也有 99.83% 准确率），
   用 AUPRC / Recall / Precision，并用 `class_weight=balanced` 处理不平衡而非简单过采样。
3. **阈值 = 策略旋钮**：阈值 0.9 → 误拦率仅 0.44% 但漏损上升；阈值 0.1 → 挽回率 94.4% 但误拦 17%。
   **最终阈值由业务成本结构决定**（漏放损失 vs 误拦人工成本），这就是风控策略岗的核心权衡思维。

## 项目结构

```

    ├── 03_threshold_sweep.csv     # 99 档阈值扫描结果
```

## 复现

```bash
python src/step1_data_check.py    # 数据体检 + 清洗
python src/step2_model.py         # 建模
python src/step3_cost_threshold.py# 阈值策略扫描
python src/step2c_oot_validation.py # OOT 时间外推验证
python src/step3c_lr_oot_cost.py   # OOT 口径成本复扫（部署阈值）
```
